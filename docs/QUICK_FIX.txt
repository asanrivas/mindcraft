THE PROBLEM:
  Error: "PartialReadError: Read error... Unexpected buffer end while reading VarInt"
  This happens when bot protocol version doesn't match server version.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

QUICK FIX (Try in Order):

1️⃣  FIX THE VERSION MISMATCH (Most Common Solution - 80% success rate)
   ─────────────────────────────────────────────────────────────────────
   
   Open: settings.js
   
   CHANGE FROM:
   "minecraft_version": "auto",
   
   CHANGE TO (pick one of these exact versions):
   "minecraft_version": "1.21.3",    ← Try this first
   OR
   "minecraft_version": "1.20.4",
   OR
   "minecraft_version": "1.20.1",
   
   IMPORTANT: Use the EXACT version your Minecraft server is running!
   
   How to find your server version:
   - Join with regular Minecraft client → look bottom-left of screen
   - Check server.properties or server launch command
   - Check recent server logs

   ✅ Then restart: npm start


2️⃣  UPDATE MINEFLAYER LIBRARIES
   ─────────────────────────────────────────────────────────────────────
   
   Run these commands:
   
   npm install
   npm update mineflayer minecraft-data
   npm start


3️⃣  RESTART YOUR SERVER
   ─────────────────────────────────────────────────────────────────────
   
   If on same machine, restart the Minecraft server:
   - Stop current server
   - Clear crash logs
   - Start fresh
   - Then start bot: npm start


4️⃣  CHECK NETWORK CONNECTION
   ─────────────────────────────────────────────────────────────────────
   
   Test if server is reachable:
   
   ping <server-host>
   
   If ping fails → server is down or host is wrong


5️⃣  VERIFY PORT IS OPEN
   ─────────────────────────────────────────────────────────────────────
   
   nc -zv <server-host> 25565
   
   Should print: Connection successful
   If fails → port not open or server not listening
